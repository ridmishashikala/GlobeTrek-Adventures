# GlobeTrek Adventures

## About the Project
GlobeTrek Adventures is a web-based tourism and travel management system developed to provide users with an easy and convenient travel experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP

## Main Features
- User Registration and Login
- Travel Destination Management
- Tour and Package Management
- Booking Management
- Database Integration
- Responsive User Interface

## Installation
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Import the provided SQL database through phpMyAdmin.
5. Configure the database connection.
6. Open `http://localhost/globetrek_adventures/`.
